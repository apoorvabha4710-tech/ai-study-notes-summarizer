# Project Roadmap

Here are some planned improvements for AI Study Notes Summarizer.

## Completed

- AI-powered study notes summarization
- Short, medium, and long summary options
- TXT file uploads
- PDF file uploads
- Download summaries as text files
- Chunk-based processing for long notes
- Streamlit web app deployment
- Project documentation and MIT License

## Planned Improvements

- Improve text splitting for headings and different sentence formats
- Combine chunk summaries into one coherent final summary
- Add automated tests
- Improve error handling for empty or scanned PDFs
- Continue testing with different subjects and note lengths
