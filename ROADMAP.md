# Project Roadmap

Here are some planned improvements for AI Study Notes Summarizer.

## Completed
- [x] Build the Streamlit application.
- [x] Generate summaries using an AI summarization model.
- [x] Offer short, medium, and long summary options.
- [x] Allow users to download summaries as text files.
- [x] Deploy the application online.

## Planned Improvements
- [ ] Support uploading PDF and TXT notes.
- [ ] Improve handling of long documents.
- [ ] Add example notes for first-time users.
- [ ] Improve error messages and input validation.
- [ ] Explore support for multiple languages.
